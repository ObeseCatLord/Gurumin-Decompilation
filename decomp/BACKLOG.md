# Decompilation backlog

Long-running task queue for after the current batch, worked top to bottom. `QUEUE.md` (generated by
`tools/gen_queue.py`) lists the individual functions; this file is the plan around it. Counts are as of 2026-11-18:
605 of 1212 functions matched, 74 open walls, 183 medium, 222 large and 114 very large functions left, 139 source
files, 210 methods still called `M_<address>` and 483 globals still called `DAT_<address>`.

Rules for every task: readable source first (no fakematches; a readable near-match goes to `open.tsv`), comments on
every function, build with `build_all.py --report`, `sync_symbols.py`, `gen_queue.py`, then commit and push.
